# ZCode Connector

把 ZCode 移动端链接套壳成安卓 App：配置一次链接，以后点开即用，支持后台保活。

## 使用方法

1. 用 Android Studio 打开本工程，等待 Gradle 同步完成
2. 手机开启"开发者选项"和"USB调试"，连电脑
3. 点 Run 安装到手机；或 Build > Build APK 生成安装包发给手机安装
4. 首次打开，粘贴你从 zcode"移动端远程控制"里复制的链接（点"复制链接"），保存
5. 之后每次打开 App 自动恢复到你的工作区

## 小米 HyperOS 必做设置（否则后台还是会被杀）

- 设置 > 应用管理 > ZCode 连接 > 省电策略 > 无限制
- 设置 > 应用管理 > ZCode 连接 > 自启动 > 允许
- 最近任务界面，下拉该 App 卡片 > 锁定
- 通知与控制中心 > 允许该 App 通知（前台服务通知才能显示）

## 功能

- 链接本地持久化，重开自动恢复
- 右上角菜单：刷新 / 更换地址
- 前台服务 + START_STICKY 保活
- 页面 DOM Storage 开启，网页侧会话不丢
